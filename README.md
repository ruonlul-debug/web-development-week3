# PocketPlan Budget Tracker

PocketPlan is a responsive, static budget-tracking page built with HTML and CSS for the Week 2 assignment.

## Files

- `index.html` contains the page structure, sample spending overview, accessible expense form, semantic expenses table, expandable help section, and budgeting video embed.
- `style.css` contains the visual design, responsive layouts, table styling, form focus states, row hover effects, and other selector examples.

## Run it

Open `index.html` in a web browser. The form is a visual prototype: its button does not add entries yet, as requested for this assignment. Google Fonts and the embedded YouTube video need an internet connection.
